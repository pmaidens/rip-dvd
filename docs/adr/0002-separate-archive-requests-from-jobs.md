# Separate Archive Requests from Archive Jobs

Approving preservation creates an Archive Request, while an Archive Job is created only when a worker starts an execution attempt after a completed Disc Inspection identifies the matching disc. The request owns durable operator intent, scheduling, cancellation, and retry state through `pending`, `running`, `needs_attention`, `cancellation_requested`, `fulfilled`, and `cancelled`; each job owns one attempt's progress and outcome. Cancelling a waiting request ends it immediately, while cancelling active work cooperatively aborts its Archive Job so operator decisions are not counted as failures. This keeps unstarted work out of Archive Job history, permits honest per-attempt statistics, and avoids overloading Detected Disc status with queue behavior.
